# 🔧 Troubleshooting Quick Reference

## Error: "NotAllowedError: Permission denied"
**Fix:** 
1. Click 🔒 in browser address bar (top-left)
2. Find "Camera"
3. Change to "Allow"
4. Refresh page
5. Try again

## Error: "NotFoundError: No camera detected"
**Fix:**
1. Check camera is connected
2. Check other apps not using camera
3. Try different browser
4. Use "Upload Photo" instead

## Camera works in test but not in app
**Fix:**
1. Go to `/add-review`
2. Hard refresh: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)
3. Try camera again

## Browser keeps blocking
**Fix:**
1. Try different browser (Chrome, Firefox, Edge)
2. Fresh browser = fresh permissions
3. Usually works immediately
